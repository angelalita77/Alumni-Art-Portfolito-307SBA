# SBA 307 - Simple Web Application Project: Portfolio Website

## 📌 Project Overview
This project is a multi-page website built to demonstrate clean HTML structure, consistent layout systems, and custom CSS styling. 

* **Duration:** 3 Days
* **Project Type:** Take-Home Skill-Based Assessment (SBA)
* **Topic:** *Art Portfolio*

---

## 🎨 Design & Structure Overview
* **Pages Included:** `index.html`, `portfolio.html`
* **Layout System:** *Flexbox*

---

## ✅ Technical Requirements Checklist

### HTML Requirements
-[X] **Multi-Page Structure:** Includes at least three (3) distinct HTML pages.
- [X] **Grid & Layout Consistency:** Grid system/layout remains consistent across all pages.
- [ ] **HTML Tag Diversity:** Uses at least ten (10) different HTML tags (e.g., `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<table>`, `<form>`, `<select>`, `<img>`, `<h1>`).
- [ ] **Table Component:** Includes at least one (1) `<table>` element.
- [ ] **Form Components:** Includes at least two (2) separate `<form>` elements.
- [ ] **Dropdown Menu:** Includes at least one (1) dropdown menu (`<select>` or CSS/Bootstrap dropdown).
- [ ] **Rich Media Content:**
  - [ ] Text content integrated across pages.
  - [ ] At least one (1) static image (`<img>`).
  - [ ] At least one (1) GIF.

---

### CSS Requirements
- [ ] **Styling Implementation Types:**
  - [ ] **Inline Styling:** Applied directly to an element via the `style` attribute.
  - [ ] **Internal Styling:** Applied using `<style>` tags within the `<head>`.
  - [ ] **External Styling:** Linked external `.css` stylesheet.
- [ ] **CSS Selectors:** Uses at least five (5) different CSS selectors (e.g., element, `.class`, `#id`, descendant, pseudo-class).
- [ ] **Color Palette:** Features complementary colors chosen for visual balance and accessibility.
- [ ] **Layout Engine:** Uses **Flexbox** and/or the **Bootstrap Grid** for positioning.
- [ ] **CSS Animations:** Implements at least two (2) distinct CSS animations/transitions.
